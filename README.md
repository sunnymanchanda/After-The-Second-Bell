# Audio Model Evaluation
Evaluation scripts for audio-language models across Vox, MUSTARD, DASED, and MusicNet datasets.

The scripts compare model predictions with ground truth and generate accuracy results by category, audio bin, answer type, and overall performance.

## Usage

```bash
python <evaluation_script>.py
```

Results are saved as CSV files in the configured output directory.
